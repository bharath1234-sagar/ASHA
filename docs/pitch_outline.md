# Pitch outline
1. Problem: ASHA workers spend time on paper registers; data is late and error-prone.
2. Solution: speak naturally (Hindi/English mix) → verified record in seconds, with read-back and explicit confirmation.
3. Safety: never guesses a beneficiary; rule-based danger warnings independent of the LLM; fixed referral wording; no diagnosis or dosage.
4. Privacy: encrypted storage, minimal metadata, secure deletion, no keys in the browser.
5. Tech: Gnani Prisma/Timbre (adapter ready, live protocol pending), Gemini extraction with rule fallback, FastAPI + WebSocket, PWA.
6. Honest status: demo uses mock speech; danger rules need clinical verification; next steps = live Gnani, verified guidelines, more languages, real register integration with consent and authentication.
